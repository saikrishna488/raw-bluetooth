Raw Bluetooth 0.7.0 — experimental Intel macOS app

1. Drag Raw Bluetooth.app to Applications. Eject this disk image.
2. Open the app from Applications.
3. This community preview is ad-hoc signed, not Apple Developer ID signed or
   notarized. If macOS blocks it, use System Settings > Privacy & Security >
   Open Anyway after attempting to open the app. Only do this for a download
   you trust. Some managed Macs may prevent opening unsigned apps.
4. Allow Raw Bluetooth under Privacy & Security > Accessibility for mouse and
   keyboard input. Relaunch if necessary.
5. Open Settings > Authorization > Install USB access and approve the one-time
   administrator request. Later sessions need no administrator authorization.
   Click Scan and put your BLE mouse or keyboard into pairing mode.
   Reinstall USB access after app updates to refresh the installed service.
   Without installation, Scan still requests administrator access per session.

USB access installs a native C++ launchd service restricted to your account.
The app bundles the C++ backend and a Python/Bumble protocol bridge.
No password is stored. To remove it after quitting the app, run in Terminal:
sudo /bin/zsh "/Applications/Raw Bluetooth.app/Contents/Resources/usb-service-install.sh" uninstall "$(id -u)"
Administrator approval is required for removal.

No Python installation or source checkout is needed. Requires an Intel Mac,
macOS 13 or later, a logged-in desktop session, and a supported external USB
Bluetooth adapter with a standard HCI interface. One external dongle is
auto-detected; choose a USB ID in Settings > USB adapter when several are
connected. The tested adapter is USB 0a12:0001. Vendor firmware loading is
not provided; internal and nonstandard controllers are excluded. Other adapters and
macOS versions need independent hardware testing. Classic Bluetooth HID,
login-screen input and microphones are not supported. System audio routing
is experimental and requires Screen & System Audio Recording permission.

Quit Raw Bluetooth before replacing or removing the app. Closing the window
keeps it running by default; use the menu bar icon to quit or release USB.

Personal device preferences, host identity and pairing keys are stored in:
~/Library/Application Support/Raw Bluetooth
They are never included in the installer. Development checkout pairings are
not automatically copied: pair devices again when first using this build.

Source, documentation and issue reports:
https://github.com/saikrishna488/raw-bluetooth

Third-party notices and firmware provenance are inside the application's
Contents/Resources directory. The default external USB path does not load
onboard Atheros firmware. System audio routing remains experimental;
this is not a replacement for macOS Bluetooth services.
